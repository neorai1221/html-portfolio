# Milestone plan

## Milestone 1 — Hebrew RTL shell, project creation, upload foundation
- Hebrew-first RTL shell with navigation and dashboard.
- Tax-year project form and explicit rule-version selection.
- Secure upload copy, validation checklist, and source-file status model.

## Milestone 2 — IBKR adapters and review
- CSV/XML deterministic adapters.
- Canonical data model and duplicate detection.
- Source-row inspection with `הצג מקור` links.

## Milestone 3 — Exchange rates
- Bank of Israel provider interface.
- Cache by currency/date/rule version.
- Explicit missing-rate workflow and exportable rate table.

## Milestone 4 — Calculations
- Decimal tax-lot engine.
- Immutable calculation steps.
- Dividends, withholding, interest, and reconciliation checks.

## Milestone 5 — Overrides and professional workflow
- Manual override audit trail.
- Loss offsets.
- Rule-version administration and professional review states.

## Milestone 6 — Output package
- Hebrew searchable PDF.
- XLSX workbook.
- JSON manifest.
- Tax-form mapping report and ZIP export.

## Milestone 7 — Advanced parsing and hardening
- PDF tables, OCR fallback, opt-in AI-assisted mapping.
- Security hardening and end-to-end tests.
