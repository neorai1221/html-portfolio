# Recommended IBKR Flex Query

Use Interactive Brokers Flex Query CSV or XML where possible. Include account info, statement period, trades, closed lots, dividends, withholding tax, interest, fees, corporate actions, cash report, forex, identifiers, transaction IDs, execution IDs, trade date, settlement date, currency, quantity, price, proceeds, commission, and tax withheld.

If a PDF does not contain transaction-level details, upload a Flex Query export instead.
